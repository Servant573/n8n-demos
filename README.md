# N8N Demos — заготовка для проработки

Три минипроекта для демонстрации возможностей N8N в контексте наших задач: внутренняя автоматизация + AI-функционал для клиентских продуктов.

## Что внутри

| Демо | Цель | Статус |
|---|---|---|
| [demo-01-cve-watcher](./demo-01-cve-watcher) | Мониторинг уязвимостей npm-пакетов по всем нашим репо с AI-классификацией | skeleton |
| [demo-02-dlq-handler](./demo-02-dlq-handler) | Обработка DLQ из RabbitMQ с AI-классификацией и роутингом ошибок | skeleton |
| [demo-03-lk-assistant](./demo-03-lk-assistant) | AI-ассистент для ЛК клиента с RAG по документам | skeleton |

Каждое демо самодостаточно — можно запускать отдельно. Общая инфраструктура (N8N + Postgres + Ollama + Mattermost) разворачивается один раз через корневой docker-compose.

## Быстрый старт

### 1. Предусловия

- Docker + Docker Compose
- 16 GB RAM минимум (Ollama с 7B моделью + остальное)
- ~20 GB свободного места (модели Ollama + данные)
- На Linux/Mac работает из коробки. На Windows — через WSL2.

### 2. Запуск инфраструктуры

```bash
cp .env.example .env
# отредактируйте .env: минимум N8N_ENCRYPTION_KEY (любая строка 32+ символов)

docker compose up -d

# Подождите 3-5 минут при первом запуске — Ollama скачает модели
docker compose logs -f ollama-bootstrap
```

После этого доступно:
- N8N UI:         http://localhost:5678
- Mattermost:     http://localhost:8065
- Postgres:       localhost:5432 (user: demo / pass: demo_secret)
- Ollama API:     http://localhost:11434

### 3. Выбор и запуск демо

```bash
cd demo-01-cve-watcher
cat README.md
# следуйте инструкциям конкретного демо
```

## Как работать с этим проектом через Claude Code

Проект намеренно оставлен как заготовка — основа для того, чтобы Claude Code или разработчик довели её до живой демонстрации. Рекомендуемая последовательность:

1. Открой [docs/CLAUDE.md](./docs/CLAUDE.md) — там инструкция для AI-ассистента.
2. Выбери одно из демо и попроси Claude Code реализовать его end-to-end, начиная с `README.md` внутри каждой папки.
3. Каждое демо описано: что демонстрирует, какие воркфлоу нужны, какие моки поднять, какие контрольные точки считать успехом.

## Переменные окружения — главное

| Переменная | Зачем |
|---|---|
| `N8N_ENCRYPTION_KEY` | Ключ шифрования credentials внутри N8N. Обязательно. |
| `OLLAMA_MODEL_CHAT` | Модель для общих задач (default: qwen2.5:7b) |
| `OLLAMA_MODEL_CODE` | Модель для кода/CVE (default: qwen2.5-coder:7b) |
| `OLLAMA_MODEL_EMBED` | Модель эмбеддингов для RAG (default: nomic-embed-text) |
| `CHAT_BACKEND` | `mattermost` (по умолчанию) или `email` или `webhook` |

## Безопасность

Всё окружение — **демонстрационное**, не для продакшна:
- Пароли в .env дефолтные
- N8N доступен без SSL
- Postgres без TLS

Перед тем как показывать коллегам/руководству на внешней машине — минимум смени пароли.

Полная security-checklist в [docs/SECURITY.md](./docs/SECURITY.md).
